 ELSB - Character Body Customization Toolkit   v1.1.1   ※非公式 unofficial
================================================================


■ これは何か

  コーエンと、ロマンス相手のアンカ・ラクラ・マラトの見た目を選ぶツールです。
  体型・髪型・髪の色・髭・目の色・肌・裸の場面を、見本の画像を見ながら 1 つの画面で選べます。
  体型を替えても、ストーリーで出る傷・血・紋様はそのまま出ます。
  ほかの作者の見た目の MOD も取り込んで、同じ画面で選べます。


■ 使い方

  1. zip をフォルダごと、ゲームのフォルダの外に解凍する
  2. Start_ELSB.bat を実行する
  3. コーエン・アンカ・ラクラ・マラトのタブで見た目を選ぶ
  4. 「適用」を押す
  5. ゲームを起動する

  ゲームは自動で見つけます (Steam・GOG)。見つからないときは「参照...」で、
  Dawnwalker と Engine が入っているフォルダを選んでください。
  選んだ内容は覚えているので、いつでも開き直して変えられます。
  画面の言語 (日本語 / English) は右上の一覧で選べます。


■ 前の版から更新する

  新しい版は、新しいフォルダに解凍してください。
  前の版で取り込んだ MOD と選んだ内容を引き継ぐには、新しい版の Start_ELSB.bat を実行する前に、
  前の版のフォルダから次の 2 つを、新しい版のフォルダの同じ場所へ写します。
    modules\external   (取り込んだ MOD)
    ELSB.ini           (選んだ内容)

  写さなかったときは、「MOD 管理」で「~mods の MOD」になった MOD を選び、「取り込む」を押すと取り込み直せます。
  取り込まずに「適用」を押すと、その MOD の ELSB の体に合わせた版が外れます (外れる前に確認の窓が出ます)。


■ 注意すること

  ・ゲームを閉じてから「適用」を押してください。

  ・ELSB のフォルダを、ゲームの Paks や ~mods の中に置かないでください。
    中のファイルが全部読み込まれてしまいます。

  ・黒い窓が 1 つ出ますが、正常です。最小化されたままにしておいてください。
    ELSB の画面を閉じれば一緒に消えます。

  ・アンカ・ラクラ・マラトの新しい体は、最初は裸の場面だけに入ります。
    服を着た場面でも使うときは「体の場面」を「全部の場面」にしてください。
    服は新しい体に合わせてあります。

  ・適用した直後の最初の起動は、ウイルス対策ソフトが新しいファイルを調べるため、
    少し時間がかかることがあります。

  ・ゲーム本体がアップデートされたら、ELSB の新しい版が出ていないか確かめてください。


■ 元に戻す

  「全部外す (バニラに戻す)」を押すだけです。
  ELSB が置いたファイルを全部外します。ほかの MOD はそのままです。

  手で消す場合、ELSB のファイルは ELSB_ で始まる物です。v1.0 のファイルは Goldwalker で始まります (開発中の名前)。
    <ゲームフォルダ>\Dawnwalker\Content\Paks\~mods\ELSB_*_P       (.pak / .ucas / .utoc)
    <ゲームフォルダ>\Dawnwalker\Content\Paks\~mods\Goldwalker*_P   (v1.0)
  互換パッチは 0ELSB_Compat、取り込んだ肌・メイク・タトゥの MOD は 0ELSB_Skin_ で始まります。
    <ゲームフォルダ>\Dawnwalker\Content\Paks\~mods\0ELSB_*_P

  「MOD 管理」でチェックを外した MOD は、消さずに次の場所へ移してあります。
    <ゲームフォルダ>\Dawnwalker\Content\ELSB_DisabledMods


■ 安全性について

  ゲームにもともとあるファイルは 1 つも書き換えません。~mods にファイルを置くだけなので、
  外せば元どおりです。

    ・exe を触りません
    ・ゲーム本体の pak を触りません
    ・セーブデータに何も書き込みません
    ・ほかの MOD を上書きしません (外した MOD は移すだけで、消しません)
    ・UE4SS などのローダーを使いません

  ELSB.ps1 はただのテキストです。実行する前にメモ帳で中を読めます。


■ ほかの MOD と一緒に使う

  ・BoDQS・Bloodywalker とは一緒に使えます (替えるデータが違います)。

  ・ほかの見た目の MOD は、zip などを「MOD 管理」タブにドラッグすると取り込めます。
    ELSB と同じ所を変える MOD は、その項目の選択肢の 1 つになります
    (どちらか 1 つを選びます)。重ならない MOD は、チェックで入れる・外すを切り替えるだけです。

  ・肌・メイク・タトゥの MOD (人物の頭や体の画像だけを替える MOD) は、取り込むと
    その人物の「肌・メイク・タトゥ」に並びます。選んでも体型は ELSB のまま、一緒に入ります。
    同じ画像は MOD の方が使われます (互換パッチが替える画像だけは、互換パッチの方が使われます)。

  ・「MOD 管理」タブの一覧には、MOD ごとに ELSB と一緒に使えるかが出ます
    (ELSB と併用 OK・ELSB の一部を置き換える・ELSB の一部とぶつかる)。
    選んでいない MOD にも出ます。MOD を選ぶと、下に詳しい説明が出ます。

  ・~mods に直接入れた MOD は「~mods の MOD」と出ます。選んで「取り込む」を押すと、
    元の zip が無くても取り込めて、人物のタブで選べるようになります。
    取り込んだ MOD は「一覧から消す」で消せます (~mods から取り込んだ物は、~mods のファイルを残します)。


■ 対応する MOD の互換 (v1.1)

  次の MOD は、ELSB の体に合わせた形 (互換パッチ) が ELSB に入っています。
  その MOD を「MOD 管理」タブに取り込み、その人物の体型を ELSB にすると、自動で使われます。
  元の MOD が必要です。互換パッチだけでは何も変わりません。

    MOD (作者)                                          選ぶ所
    Thicc Anca by MM (MistrianMilker)                    アンカの服
    Revealing Thicc Anca by MM (ScrumpChewie)            アンカの服
    Wrong Sized Tanktop For Thicc Anca (ScrumpChewie)    アンカの服
    Revealing Anca (Joell560)                            アンカの服
    Revealing Lacra (Joell560)                           ラクラの服
    Coen's Nude Mod (dakyoz)                             コーエンの性器・マラトの性器

  ・取り込むと、「MOD 管理」の一覧に「ELSB 対応」と出ます。
  ・服の MOD を選ぶと、「アンカの体の場面」「ラクラの体の場面」は自動で「全部の場面」になります。
  ・Coen's Nude Mod を取り込むと、コーエンのタブに「性器」、マラトのタブに「マラトの性器」が出ます。
    別々に選べます。見えるのは、裸の場面と、ELSB で下着を外した場面です。
  ・使い方と、今ゲームに入っているかは、「MOD 管理」タブで MOD を選ぶと下の説明に出ます。
  ・MOD の版が違うと (作者が更新した場合など)、互換パッチは使われず、元の MOD がそのまま入ります。


■ うまくいかないとき

  ・ウィンドウが出ない
      zip をフォルダごと解凍し直してください。
      Start_ELSB.bat・ELSB.ps1・modules・assets は同じ場所に置いたままにします。

  ・見た目が変わらない
      ゲームを再起動してください。
      「MOD 管理」タブで、その MOD に「今は使われていない」が出ていないか確かめてください。

  ・Xbox / Game Pass 版
      今は対応していません。


■ MOD 作者の方へ (ELSB に対応させる方法)

  ・書庫 (zip / rar / 7z) に elsb_preview.png (.jpg・.webp も可) を入れると、
    取り込んだときに、その画像が選択肢の見本になります。
    長い辺が 1600 画素より大きい画像は、ELSB が縮めます。
    この名前の画像が無いときは、書庫の画像が 1 枚だけのときだけ、その画像を使います
    (T_ で始まる画像は使いません)。

  ・書庫に elsb_item.txt を入れ、1 行目に項目の名前 (下の一覧) を書くと、その項目に並びます。
    none と書くと、どの項目にも並ばず、チェックで有効・無効を切り替えるだけになります。
    書いた項目と同じファイルを置き換えない MOD は、ELSB が項目を決めます。
    性器と肌・メイク・タトゥの項目だけは、同じファイルが無くても並べられます。

  ・色違いなどの版は、書庫を分けるか、1 つの書庫の中で版ごとにフォルダを分けてください。
    同じファイルを置き換え合うフォルダは、版ごとに 1 つの選択肢
    (「書庫の名前 - フォルダの名前」) になります。
    elsb_preview.png と elsb_item.txt は、版ごとのフォルダに入れます。
    どの版とも重ならないファイル (共通の部品) は、全部の版に入ります。
    FOMOD には対応していません。

  ・肌・メイク・タトゥの MOD (人物の頭や体の画像だけの MOD) は、取り込むとその人物の
    「肌・メイク・タトゥ」に並び、ELSB の体型と一緒に入ります。
    重なる画像は MOD の方が使われるように、ELSB がファイルの名前の頭に 0ELSB_Skin_ を付けて置きます。

  ・ELSB のファイルは ELSB_ で始まります。~mods では名前が小さい方が勝ちます。

  ・MOD を更新して取り込み直しても、遊ぶ人が選んだ項目と、手で付けた見本はそのまま残ります。

  elsb_item.txt に書く項目の名前:
    コーエン  body, hair, hair_color, beard, beard_color, eyes, romance, coen_uw, genitals, skin
    アンカ    anca_body, anca_scope, anca_outfit, anca_skin, anca_hair, anca_hair_color
    ラクラ    lacra_body, lacra_scope, lacra_outfit, lacra_skin, lacra_hair, lacra_hair_color,
              lacra_eyes
    マラト    marat_body, marat_scope, marat_outfit, marat_skin, marat_romance, marat_hair,
              marat_hair_color, marat_beard, marat_beard_color

  服を ELSB の体に合わせる方法などは、Nexus の ELSB のページの「FOR MOD AUTHORS」にあります。
